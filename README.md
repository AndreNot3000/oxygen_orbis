## 🌟 Key Features

- **🍫 Chocolate & Caramel Luxury Theme**: Warm deep espresso backgrounds (`#0C0502` to `#1A0C06`), rich caramel gold accents (`#C9854A`), and silky glassmorphism with ambient lighting.
- **🎥 Scroll-Expanding Hero Experience**: Centered cinematic video reel that expands into full landscape upon scroll with split title typography.
- **🚆 Lagos-to-Ibadan Rail Staycation Advantage**: Interactive travel guide detailing the scenic 2-hour train journey from Mobolaji Johnson Station to Moniya with VIP station chauffeur pickup.
- **🛎️ Interactive 4-Step Booking Engine**: Direct room selection (Deluxe King, Executive Suite, Presidential Suite), dynamic currency conversion (NGN / USD), stay enhancements/add-ons, and multi-channel checkout (Paystack & Direct Bank Transfer with receipt verification).
- **🪪 Cryptographic Stay Pass & QR Generator**: Real-time tamper-proof digital stay pass with HMAC-SHA256 verification and downloadable printable A4 guest voucher.
- **💻 Reception Front Desk Staff PMS**: Operational dashboard featuring live room status tracking (Clean, Dirty, Cleaning, Inspected), guest check-in scanner, and walk-in reservation creation.
- **📈 Management Pitch Deck & OTA Commission Calculator**: Interactive investor presentation comparing direct booking revenue vs. Booking.com / Expedia commissions, with dynamic ADR and RevPAR projections.
- **✨ Full-Screen Glassy Footer**: Custom-designed responsive footer with animated sliding arrow links, column glowing dots, ambient glass breathing glow, and bottom-anchored metallic branding.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/AndreNot3000/oxygen_orbis.git
cd oxygen_orbis
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment variables
Copy the template and fill in your keys:
```bash
cp .env.example .env
```

### 4. Run the development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🧪 Testing

Run the automated test suite covering all modules:
```bash
npm test
```

Build for production:
```bash
npm run build
```
